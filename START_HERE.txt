PLANORA — NEOSTATS HACKATHON PROJECT
===================================

This app uses Next.js + TypeScript, Express + Prisma, and LOCAL PostgreSQL. Docker is not required. No cloud database is used.

BEFORE STARTING
- Install Node.js 22+ and PostgreSQL 14+.
- Start PostgreSQL and create a database named neostats_pm.
- Extract this ZIP into a normal writable folder.

BACKEND (PowerShell terminal 1)
1. cd backend
2. Copy-Item .env.example .env
3. Edit .env and replace YOUR_POSTGRES_PASSWORD with your local PostgreSQL password. Replace JWT_SECRET with a long random value.
4. npm ci
5. npm run db:generate
6. npm run db:deploy
7. npm run db:seed
8. npm run dev

Keep this terminal running. Test http://localhost:4000/health

FRONTEND (PowerShell terminal 2)
1. cd frontend
2. Copy-Item .env.example .env.local
3. npm ci
4. npm run dev
5. Open http://localhost:3000

- Do not commit .env files or real secrets.
